## freeCodeCamp-React
Portafolio de mini proyectos para la certificación en bibliotecas de desarrollo front-end

Este curso enseña las bibliotecas que los desarrolladores usan para construir páginas web: React, TypeScript y más.

Para obtener la certificación en bibliotecas de desarrollo front-end requiere:

- Completar los cinco proyectos requeridos para calificar para el examen de certificación (los cuales estarán en este repositorio)
- Aprobar el examen de certificación en bibliotecas de desarrollo front-end (basado en los proyectos antes citados).
